Design system

Every rule on this page comes from design-system.css, which is the only place the look of this product is defined. The page loads that file and nothing else, so if something here renders wrongly, the system is genuinely missing it.

Working rule: reach for a pattern that already exists before writing a new one. Eight patterns used everywhere beat forty used once each, and consistency is worth more here than novelty - this is a tool people use every day, not a thing they look at once.

Colour

The interface is neutral. Westpack green marks the primary action, the current page and the focus ring; it is not a background. Status colours carry meaning, and every one of them is paired with a word, because colour alone is not a signal everybody can read.

Objective tones

These identify a campaign objective, and they are the one place in the product where colour is doing real work: the reader has to carry a hue from a stacked bar to the row beneath it. They live in styles.css as --tone-*-rgb channel triples so one token serves a solid fill and a translucent one, and a test fails if a panel paints an objective with anything but its own token.

Typography

One family, IBM Plex Sans, at every size. The scale is built for density: the page title is 22px and the body is 14px, because this is a tool full of figures rather than a page to be read once. Numerals are tabular everywhere, so a column of figures lines up without anyone asking it to.

Space and radius

Spacing is on a 4px base. It is how the interface says what belongs together, so it is worth taking from the scale rather than picking a number that looks right on one screen. Radius is small and consistent: above 12px an interface starts to read as a set of bubbles rather than a set of surfaces.

Buttons

Four levels. Within any one context there is exactly one primary action; everything else is secondary, ghost or danger. A screen where every button is loud is a screen where none of them is, which is what the old red-gradient primary and cream-gradient secondary amounted to.

A destructive action never looks like the default one, and anything irreversible asks first. Hover changes colour rather than moving the control: a button that lifts on hover moves the row under the reader's cursor.

Forms

Label above, control, helper or error beneath. Every control is 34px so a row of them shares one baseline without anyone nudging it. Labels are sentence case everywhere - they used to be uppercase on the ads screens and sentence case on the Klaviyo ones, which made one control look like two.

Badges and status

A badge carries a word. Colour supports it and never replaces it, so a reader who cannot tell the green from the amber still reads “Active” and “Paused”. A change badge carries an arrow as well as a tone, and it names the period it was measured over, because two badges on one screen can cover different windows.

Metrics

The number is the message; the label above and the comparison below are set smaller so the eye lands on the figure. Metrics that belong together share one bordered strip divided by hairlines rather than sitting in a row of floating cards - shared edges make figures easier to compare, and stop a page of eight numbers reading as eight competing objects.

New customers 1.284 ↑ 12,4% 1-18 sep vs 1-18 aug
Cost per new customer 186 kr. ↓ 8,2% 1-18 sep vs 1-18 aug
Spend 238.904 kr. → 0,4% last 30 days
ROAS 3,12 ↓ 5,8% last 30 days

Where there is nothing honest to compare against, there is no badge. A “0,0% flat” on the first of the month asserts that nothing changed, which is a different claim from saying nothing.

Tables

The most important component in the product. Rows are compact, separators are hairlines rather than zebra stripes, headers stay put when the body scrolls, and every figure is right-aligned with tabular numerals so two rows can be compared by eye.

Toolbar and filters

One toolbar for the whole product: filters on the left, actions on the right, everything on the same control height. What is filtered has to be visible without opening anything, and there is always a way back to the default.

Tabs

Underline tabs switch between views of the same thing. A segmented control chooses one option from a small fixed set. They do different jobs and never appear on the same screen for the same decision.

States

Nothing in this product is allowed to render as a blank area or a raw technical message. Each state says what happened and, where the reader can do something about it, what that is. A missing number is acceptable; a wrong one is not.
