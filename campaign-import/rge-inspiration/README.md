# RGE inspiration inbox

Use this folder for manually selected Really Good Emails references.

- Add screenshots you are permitted to use for internal inspiration.
- Add source URLs to `links.txt`, one URL per line.
- Keep attribution and source URLs with every imported reference.
- Imported references are pattern inspiration only and must not be copied directly.

Automated scraping is intentionally not used because the RGE Collection terms prohibit automated access and copying.
