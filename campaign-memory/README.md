# Campaign Memory Library

This directory contains structured analyses of historical campaign screenshots.

- `imports/` contains one immutable-source analysis record per screenshot.
- `manifest.json` is the searchable index generated by the import script.
- `external/` contains separately indexed external inspiration references with attribution metadata.
- Every new record starts as `needs_review` and is not treated as an approved or high-performing reference.
- `approved-references.json` is the explicit allowlist used by Campaign Brain. An analyzed screenshot cannot influence production until its ID is curated there.
- Production selects up to five brief-relevant owned Westpack references and treats them as the primary design memory; external references are limited to one secondary abstract reference.
- The producer visually inspects up to four of those owned emails so hierarchy, image choreography, CTA rhythm and tone influence the actual output rather than only the text prompt.
- Original screenshots remain untouched in `campaign-import/unsorted-email/`.

Run a small calibration batch:

```powershell
node scripts/analyze-campaign-import.js --limit 3
```

Analyze all new screenshots:

```powershell
node scripts/analyze-campaign-import.js
```

Analyze manually selected RGE references:

```powershell
node scripts/analyze-campaign-import.js --source rge
```
